# Sparkz in the Dust – Playtest

Hier gibt es die jeweils aktuelle Playtest-Version von **Sparkz in the Dust** (Action RPG, Windows).

## ⬇️ Download

**[Neueste Playtest-Version herunterladen](https://github.com/bvultrex/Sparkz-in-the-Dust-Playtest/releases/latest)**

Auf der Release-Seite unter *Assets* die `.zip` herunterladen. Ältere Versionen findest du unter [Releases](https://github.com/bvultrex/Sparkz-in-the-Dust-Playtest/releases).

## Installation

1. Zip herunterladen und komplett entpacken (nicht direkt aus der Zip starten).
2. Im entpackten Ordner `Sparkz in the Dust.exe` starten.
3. Falls Windows SmartScreen warnt: *Weitere Informationen* → *Trotzdem ausführen* (der Build ist nicht signiert).

Alle Details zur Version, Steuerung und bekannten Punkten stehen in der `LIESMICH.txt` im Ordner.

## Koop

Im Koop müssen alle Spieler eine Version mit **demselben Koop-Protokoll** nutzen. Welche Versionen zusammenpassen, steht in den Release-Notes.

## Prüfsumme

Zu jeder Zip gibt es eine `.sha256`-Datei, mit der du prüfen kannst, ob der Download vollständig ist:

```powershell
Get-FileHash .\Sparkz_in_the_Dust_Playtest_*.zip -Algorithm SHA256
```
